# Jeebli | جيبلي

النسخة الأولى من تطبيق العميل لمنصة جيبلي، مربوطة مباشرة بمشروع Supabase.

## الموجود حالياً

- واجهة عربية RTL مخصصة للهاتف.
- إنشاء حساب وتسجيل دخول عبر Supabase Auth.
- إنشاء ملف مستخدم تلقائياً في `profiles`.
- اختيار نوع الخدمة: تكسي، خصوصي، توصيل، بين المحافظات.
- التقاط موقع الانطلاق من GPS عند سماح المستخدم.
- إنشاء رحلة حقيقية في جدول `rides`.
- عرض آخر رحلات المستخدم.
- تحديث الرحلات لحظياً عبر Supabase Realtime.
- RLS مفعل في قاعدة البيانات.

## التشغيل

المشروع Static Web App. شغّل الملفات عبر أي HTTP server محلي أو انشرها على خدمة استضافة ثابتة. لا تفتح `index.html` فقط عبر `file://` إذا أردت أن تعمل خصائص المتصفح والموقع بشكل موثوق.

## هيكل الملفات

- `index.html` الواجهة.
- `styles.css` الهوية والتنسيق.
- `app.js` Supabase Auth + Database + Realtime.

## المرحلة التالية

الخريطة الفعلية، اختيار نقطة الانطلاق والوجهة بصرياً، احتساب المسافة والسعر، شاشة البحث عن سائق، تفاصيل السائق، حالات الرحلة الكاملة، الإشعارات، الملف الشخصي والعناوين المحفوظة.
